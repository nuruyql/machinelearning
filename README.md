# Первичный анализ данных

## Описание

Проект выполнен в рамках задания уровня B по первичному анализу данных.

## Структура проекта

- `data/` — исходный датасет.
- `notebooks/` — Jupyter Notebook с анализом.
- `README.md` — описание проекта.

## Окружение

Для проекта использован `venv`, поскольку он позволяет создать изолированное Python-окружение и избежать конфликтов между зависимостями разных проектов.

## Используемые библиотеки

- pandas
- matplotlib
- jupyter
